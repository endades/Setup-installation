# enCONTROL Environment Requirements

## 1. Requirements for Configuring enCONTROL Workstations

Before installing and configuring enCONTROL, it is necessary to carry out some preliminary configurations in the environment where the application will run.

### 1.1. Antivirus and Firewall

Follow the recommendations in section **2. Antivirus and firewall settings** under [System Configuration](Configuracion_Sistema.md).

---

## 2. Minimum System Requirements – enCONTROL

For the workstations where **enCONTROL** will be implemented, a wired-connected computer is required at the factory.

### 2.1. Minimum Equipment Configuration

**Computer equipment:**

- Can be a **NUC** (small and compact computer).
- Can be **refurbished**.
- It is sufficient that it has basic functional capacity to run the application and wired network connectivity.

**Required peripherals:**

- 1 Monitor (Touchscreen is recommended)
- 1 Mouse
- 1 Keyboard

## 3. Permissions

- It is recommended that the equipment has **all necessary permissions** to ensure the proper functioning of the application and connectivity with the required systems.

---

## 4. Connectivity

- The equipment must be installed with a **wired network connection**.
- Stable access to the enCONTROL system must be guaranteed from the factory workstation.
